## Preservation and treatment

Untouched HEIC captures remain local because they contain GPS coordinates. Their narrow ignore rules keep those files out of public Git history. The full-resolution public JPEGs, gallery copies, enhanced images and [provenance](edits.json) are versioned in this repository.

Enhanced alternatives were prepared with the built-in image tool for restrained lighting and presentation changes, with an S9 Engineering signature and an **AI-enhanced photo** label. Reference photographs retain the actual surface texture and print imperfections. [Initial prompts](prompts.md) and [additional prompts](additional-prompts.json) document the treatments.

Channel-specific exports and upload ZIPs remain local, separate from these GitHub assets.
